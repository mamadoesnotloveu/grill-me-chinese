# 中文与术语规则

- 跟随用户的主要语言。中文输入使用自然、准确的简体中文，不照搬英文句式。
- 关键产品或工程术语首次出现时用“中文（English）”；之后固定同一译法。
- 没有稳定译法或翻译会损害精度时保留英文，并简短解释。
- 产品名、品牌名、模型名、框架名、API 名、字段名和代码标识符保持原文。
- 不把不同角色统称为用户：区分使用者（user）、客户（customer）、购买者（buyer）、决策者（decision-maker）、管理员（administrator）和操作者（operator）。
- 区分验证（validation）与校验（verification）、可逆性（reversibility）与回滚（rollback）、约束（constraint）、依赖（dependency）与假设（assumption）。产品成功指标和工程验收标准分别表达。
- 翻译会改变决策含义时，列出可能解释并请用户确认。
- 在对话中维护术语映射，阶段总结和最终输出沿用已确认译法。
- 专业术语较多时，在最终交付物附术语表。
